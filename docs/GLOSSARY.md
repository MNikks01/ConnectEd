# Glossary

Definitions of product, domain, and technical terminology used across this documentation. Identifiers in `MONOSPACE` are taken verbatim from the code.

| Term                                                    | Meaning                                                                                                                                                          |
| ------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ConnectEdApp**                                        | The mobile (Android/Expo) application; also the umbrella product name. Used by individual users.                                                                 |
| **GetConnected**                                        | The website (React) brand/app. School-administration portal + desktop client for users.                                                                          |
| **User account**                                        | An individual account stored in the `USERS` collection (student, parent, teacher, principal, or general user).                                                   |
| **School account**                                      | An institutional account stored in the `SCHOOLS` collection; web-login only; owns academic data.                                                                 |
| **Status** (`USER_CURRENT_STATUS`)                      | The academic role a user has declared: `STUDENT`, `PARENT`, `TEACHER`, `PRINCIPAL`, or empty for a general "User".                                               |
| **General User / "Just a User"**                        | A user with no academic status — social features only.                                                                                                           |
| **Verification**                                        | The process by which a school confirms a member's declared role, flipping `VERIFIED_STUDENT/TEACHER/PRINCIPAL` (etc.) from false to true. Gates academic access. |
| **Verification Request**                                | A pending request a user submits to a school/class asking to be verified (`VERIFICATION_REQUESTS`).                                                              |
| **Verified Member**                                     | A user the school has approved for a class/role (`VERIFIED_MEMBERS`).                                                                                            |
| **Class (academic)**                                    | A specific **Medium + Class + Section** combination, e.g. _English Medium · Class 5 · Section A_.                                                                |
| **Class key** (`classKey`)                              | The encoded identifier for a class used as a Firestore path segment, e.g. `EngClass5SecA`. Generated by `returnedMedClsSec()`.                                   |
| **Medium**                                              | Language of instruction — English or Hindi.                                                                                                                      |
| **Section**                                             | A division within a class — Section A through E.                                                                                                                 |
| **Class Teacher**                                       | A teacher allocated (`CLASS_TEACHER_DATA`) as the responsible teacher for one class; approves that class's student/parent leave.                                 |
| **Currently Selected Child** (`CURRENT_SELECTED_CHILD`) | The child a parent is currently viewing; scopes all academic views for that parent.                                                                              |
| **Child** (`CHILDS_INFO`)                               | A record under a parent linking to a school/medium/class/section (`CHILDS_SCHOOL_ID`, etc.).                                                                     |
| **Projects & Homeworks**                                | The academic-work module. Three work types: **Daily Homework**, **Assignment**, **Project**.                                                                     |
| **Notice Board**                                        | School-wide announcements (`NOTICE_BOARD/NOTICES_SENT`).                                                                                                         |
| **Upcoming Events**                                     | School events (`SCHOOL_EVENTS/ALL_EVENTS`).                                                                                                                      |
| **Syllabus Covered**                                    | Curriculum-progress tracking per class/subject.                                                                                                                  |
| **Timetable**                                           | A per-class schedule image uploaded by the school.                                                                                                               |
| **Leave Application**                                   | A formal leave request. Student/parent → class teacher; teacher → principal. States: Received / Accepted / Rejected.                                             |
| **Complaints & Feedback**                               | Member-to-school channel storing `COMPLAINTS` and `SUGGESTIONS`.                                                                                                 |
| **Feed**                                                | The aggregated timeline of posts from followed schools and users.                                                                                                |
| **Post**                                                | A timeline entry (text + optional images) under `POSTS/ALL_POSTS`, with `POST_LIKES` and `POST_COMMENTS`.                                                        |
| **Follow**                                              | A one-directional subscription to a school or user (`FOLLOWING`/`FOLLOWERS`).                                                                                    |
| **Connection / Friend**                                 | A mutual relationship formed by accepting a request (`REQUESTS_SENT`/`REQUESTS_RECIEVED` → `CONNECTIONS/CONNECTED_USERS`).                                       |
| **Message**                                             | A private 1:1 message (`MESSAGES_SENT`/`MESSAGES_RECIEVED`); `IS_VIEWED` tracks read state.                                                                      |
| **`VIEWED_BY`**                                         | An array on academic items (notices, homework) listing user IDs who have read the item; drives unread badges.                                                    |
| **Badge**                                               | A live in-app unread/pending counter (messages, requests, notices, homework, leave).                                                                             |
| **Push token** (`PUSH_NOTIFICATION`)                    | The device's Expo push token stored on the user document, used to send notifications.                                                                            |
| **Expo Push**                                           | The Expo push service (`exp.host`) the app calls to deliver notifications.                                                                                       |
| **`USER_NAME` / `SCHOOL_NAME` (as path)**               | The entity's name used as a Firestore path segment (a.k.a. `USER_PATH_COLLECTION` / `SCHOOL_PATH_COLLECTION`).                                                   |
| **Onboarding flag** (`ConnectEdAppLaunched`)            | Local storage flag ensuring the onboarding carousel shows only on first launch.                                                                                  |
| **AdMob**                                               | Google Mobile Ads — the banner-ad system in the mobile app.                                                                                                      |
| **Subscription**                                        | Planned school billing area (currently a stub).                                                                                                                  |
| **Firebase project `random-21953`**                     | The single backend shared by both apps (Auth, Firestore, Storage, Analytics, Hosting).                                                                           |
| **Assumption**                                          | A stated inference in this documentation that could not be fully proven from code.                                                                               |
| **Inferred**                                            | A lighter-weight, likely-but-unverified conclusion from naming/structure.                                                                                        |

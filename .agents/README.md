# .agents — Team Role Charters

`Status: Accepted` · `Last updated: 2026-07-28`

Each file defines a **role** on the ConnectEd engineering org — its mission, responsibilities, the docs it owns,
its inputs/outputs, and the quality bar it upholds. They double as **prompts/personas** for AI subagents and as
**onboarding charters** for humans in that role.

> These describe *responsibilities*, not seats — one person (or one AI subagent invocation) may wear several.

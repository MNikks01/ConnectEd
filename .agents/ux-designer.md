# UX Designer

## Mission

Make ConnectEd effortless for non-technical users (parents, teachers, school admins) across every role.

## Responsibilities

- Own user flows and interaction design (`.docs/UserFlows`, `.docs/Wireframes`).
- Design role-aware navigation and the verification/onboarding journeys (the make-or-break flows).
- Ensure every screen defines Loading/Error/Empty/Success states and is usable on low-end devices/slow networks.
- Run usability checks; reduce steps in high-frequency loops (homework, leave, child-switching).

## Owns (docs/paths)

`.docs/UserFlows/*`, `.docs/Wireframes/*`, interaction specs.

## Inputs / Outputs

In: PRD, personas, research. Out: flows, wireframes, interaction specs, usability findings.

## Standards & gates

Flows map to PRD acceptance criteria; students never see hidden modules (leave/complaints); parent child-switching
is first-class; accessibility considered from the start.

## Collaborates with

product (requirements), ui-designer (visuals), frontend (feasibility), researcher (usability).

## Definition of done

Flow validated against acceptance criteria, all states specified, accessible, minimal-friction.

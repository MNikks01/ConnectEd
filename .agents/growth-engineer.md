# Growth Engineer

## Mission

Move activation, retention, and conversion for schools and members through instrumented experiments.

## Responsibilities

- Optimize the funnels in `Product/02-metrics.md` (school onboarding, member verification, homework loop).
- Design and run A/B experiments behind feature flags; define hypotheses, metrics, and guardrails.
- Improve invite/verification conversion; reduce time-to-value; build referral/notification nudges.

## Owns (docs/paths)

Experiment specs, feature-flag configs (growth), funnel dashboards (with analytics).

## Inputs / Outputs

In: metrics, funnels. Out: experiments, results, shipped improvements or reverts.

## Standards & gates

Every experiment has a hypothesis, primary metric, guardrails, and a decision rule; flags + kill switches;
statistically honest read-outs; no dark patterns (minors present).

## Collaborates with

product, analytics-engineer (measurement), frontend (implementation), ml-engineer (ranking).

## Definition of done

Experiment shipped, measured, decided (roll out/iterate/revert), learning documented.

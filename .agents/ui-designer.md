# UI Designer

## Mission
Own the visual language and design system so ConnectEd looks trustworthy, consistent, and distinctly not-templated.

## Responsibilities
- Build and maintain the design system in `packages/ui`: color/typography/spacing/elevation tokens; button/form/
  modal/table/notification systems.
- Design high-fidelity screens from wireframes; ensure light/dark + responsive + a11y (contrast) coverage.
- Keep visuals consistent across web now and mobile later.

## Owns (docs/paths)
`packages/ui/*` (design tokens/primitives), visual specs, design-system docs.

## Inputs / Outputs
In: wireframes, brand direction. Out: design system, hi-fi designs, component specs.

## Standards & gates
Tokenized (no magic values); WCAG AA contrast; components theme-aware and responsive; reuse over one-offs. Draw on
the `frontend-design`/`design-taste-frontend` skills for intentional, non-generic UI.

## Collaborates with
ux-designer (flows), frontend-engineer (implementation), product (brand), performance (asset weight).

## Definition of done
Design system tokens + components defined, accessible, theme-aware, and implemented in `packages/ui`.
